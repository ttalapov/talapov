# Талапов Т. К. — Лендінг-резюме

Сучасна, адаптивна односторінкова презентація викладача комп'ютерних та економічних дисциплін.

## 🎨 Стек і архітектура

- **HTML5** — семантична розмітка, ARIA, Schema.org JSON-LD
- **CSS3** — CSS-змінні, Grid, Flexbox, mobile-first
- **Vanilla JavaScript** — без фреймворків і залежностей
- **Шрифт:** Manrope (Google Fonts)
- **Палітра:** офіційні бренд-кольори Facebook (#1877F2 / #42B72A)

## 📁 Структура проєкту

```
landing/
├── index.html              # Головна сторінка
├── README.md               # Цей файл
│
├── css/
│   ├── reset.css           # Скидання браузерних стилів + a11y
│   ├── variables.css       # Дизайн-токени (FB-палітра, відступи, шрифти)
│   └── style.css           # Основні стилі — секції, компоненти, адаптив
│
├── js/
│   └── main.js             # Sticky header, mobile nav, фільтри, анімації
│
└── img/
    ├── avatar.jpg          # Фото для Hero
    └── favicon.svg         # Іконка вкладки
```

## 🧩 Секції лендінга

1. **Header** — sticky-навігація з blur-ефектом
2. **Hero** — фото, ім'я, статистика (роки, публікації, дисципліни)
3. **About** — 4 картки про ключові сильні сторони
4. **Skills** — 6 категорій навичок (БД, мережі, хмари, програмування, e-Learning, САПР)
5. **Experience** — таймлайн досвіду роботи
6. **Education** — паралельні колонки: освіта + сертифікати
7. **Publications** — 13 публікацій з фільтрами за типом
8. **Contact** — 6 каналів зв'язку + CTA-блок
9. **Footer** — копірайт + соцмережі

## 📱 Адаптивність

| Брейкпоінт | Поведінка |
|---|---|
| **≤ 480px** | Кнопки на повну ширину, зменшені заголовки |
| **≤ 768px** | Mobile-меню (бургер), 1 колонка скрізь, фільтри з горизонтальним скролом |
| **≤ 1024px** | Hero в 1 колонку, навички та контакти у 2 колонки |
| **> 1024px** | Повний десктопний лейаут |

## ♿ Доступність (WCAG 2.1)

- Семантичні HTML5-теги (`<header>`, `<main>`, `<nav>`, `<section>`, `<article>`, `<footer>`)
- ARIA-атрибути на інтерактивних елементах
- Контраст тексту відповідає AA-рівню
- Підтримка `prefers-reduced-motion` (відключає анімації)
- Видимий focus-стан на всіх інтерактивних елементах
- Усі іконки мають `aria-hidden="true"` або `aria-label`

## ⚡ Продуктивність

- Без зовнішніх JS-фреймворків
- Шрифти з `preconnect` і `display=swap`
- Анімації на CSS (де можливо)
- `IntersectionObserver` замість scroll-listeners для reveal-ефектів
- Lazy-загрузки картинок не використовується для Hero (LCP-оптимізація)

## 🚀 Як запустити

### Локально
```bash
# Просто відкрийте index.html у браузері
# Або через простий сервер:
npx serve .
# чи
python3 -m http.server 8000
```

### GitHub Pages
1. Створіть репозиторій
2. Завантажте всі файли
3. Settings → Pages → Branch: `main` → Save
4. Сайт буде доступний за адресою `https://username.github.io/repo-name/`

### Vercel
1. `vercel` у терміналі (потрібен Vercel CLI), або
2. Перетягніть папку на [vercel.com/new](https://vercel.com/new)
3. Готово — автоматично отримаєте `*.vercel.app` адресу

## 🎯 SEO

- Семантичні `<h1>` — `<h3>`
- Open Graph + Twitter Card мета-теги
- Schema.org JSON-LD (`Person`)
- Дескриптивні `alt`-атрибути
- Канонічна структура URL (anchor-навігація)

## 🔧 Кастомізація

Усі кольори, відступи, шрифти — у `css/variables.css`. Щоб змінити палітру, відредагуйте лише цей файл.

```css
:root {
  --color-primary: #1877f2;       /* Основний синій */
  --color-secondary: #42b72a;     /* Зелений CTA */
  /* ... */
}
```
